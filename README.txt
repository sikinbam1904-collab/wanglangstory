# วังหลัง — ชะตารักเหนือบัลลังก์ (Reborn)

## ในแพ็กเกจนี้
- เนื้อเรื่อง 20 บทภาษาไทย
- แต่ละบทมี 3 ตัวเลือก เพิ่ม/ลดคะแนนหลายด้าน และบันทึกผลของทางเลือก
- ข้อความตอบสนองหลังเลือกแตกต่างกันตามคำตอบ และคำถามในบทถัดไปเปลี่ยนตามตัวเลือกก่อนหน้า
- 6 จุดจบ คำนวณจากคะแนนรวม
- ภาพฉากหลัง SVG 20 ภาพใน `assets/scenes/`
- ภาพตัวละคร placeholder SVG 10 ภาพใน `assets/characters/` (พื้นหลังโปร่งใสแบบเวกเตอร์เพื่อแทนภาพ AI ทีหลัง)
- เสียงบรรยากาศสร้างด้วย Web Audio API
- เซฟอัตโนมัติใน browser localStorage

## วิธีเล่น
เปิดผ่านเว็บเซิร์ฟเวอร์หรืออัปโหลดขึ้น GitHub Pages (การเปิด `index.html` โดยตรงบางเบราว์เซอร์อาจบล็อกการโหลด `story.json`)

## วิธีเปลี่ยนภาพภายหลัง
### ฉากหลัง
แทนที่ไฟล์ใน `assets/scenes/` โดยคงชื่อเดิม เช่น `ch01_gate.svg` หรือแก้ชื่อใน `story.json` ในฟิลด์ `scene` ให้ตรงกับไฟล์ใหม่

### ตัวละคร
แทนที่ไฟล์ใน `assets/characters/` โดยคงชื่อเดิม เช่น `heroine.svg` ด้วย PNG ที่ชื่อ `heroine.png` แล้วแก้ `game.js` ในการตั้งค่า `characterImage.src` ให้เลือกนามสกุล `.png` แทน `.svg` หรือปรับให้ชื่อไฟล์ตัวละครอยู่ใน `story.json` ตามต้องการ
แนะนำภาพฉาก 1920x1080 แนวนอน 16:9 และภาพตัวละคร PNG พื้นหลังโปร่งใส 768x1152 หรือ 1024x1536

## คะแนนและจุดจบ
คีย์คะแนน: `love`, `power`, `wisdom`, `revenge`, `trust`, `secret`
เงื่อนไขจุดจบอยู่ใน `story.json` สำหรับอ่านอ้างอิง และลำดับการตัดสินจริงอยู่ในฟังก์ชัน `resolveEnding()` ใน `game.js`
